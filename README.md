# SKNH Claim Code Check

เว็บตรวจสอบรหัส ICD-10, ICD-9-CM และรหัสอุปกรณ์ (Instrument) ของ 3 สิทธิ (UC / ประกันสังคม / กรมบัญชีกลาง) สำหรับแพทย์ นักเวชสถิติ และ claimer — ศูนย์จัดเก็บรายได้ โรงพยาบาลสกลนคร

**เปิดใช้งาน:** https://pamanee-ui.github.io/sknh-claim-code-check/

- คีย์รหัส Instrument → ICD-9 ที่ต้องลงคู่จึงจะเบิกได้ (UC) พร้อมเงื่อนไข
- คีย์รหัส ICD-9 → รหัส Instrument UC ที่เบิกคู่ได้
- เทียบรายการ หน่วย และอัตราเบิกของ 3 สิทธิ

หน้าเว็บเป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่เก็บข้อมูลผู้ป่วย และไม่ส่งข้อมูลออกไปที่ใด

## แหล่งที่มาและลิขสิทธิ์

- ICD-10 Volume 1, 5th ed. 2016 © World Health Organization — ใช้เพื่องานภายในโรงพยาบาลแบบไม่แสวงหากำไร ไม่ได้รับรองโดย WHO
- ICD-9-CM Tabular List of Procedures FY15 ฉบับ Thai DRG
- ประกาศอัตราค่าอุปกรณ์และอวัยวะเทียม สปสช. (UC) · สิทธิประกันสังคม หมวด 2 (17 เม.ย. 69) · กรมบัญชีกลาง ว 751 ลว. 28 พ.ย. 2567
- การจับคู่ Instrument ↔ ICD-9 จากคอลัมน์ "สรุป ICD 9" ที่ผู้เชี่ยวชาญของโรงพยาบาลตรวจแล้ว

ข้อมูลบางส่วนถอดจากเอกสารสแกน (OCR) กรุณาตรวจกับเอกสารต้นฉบับก่อนใช้เบิกจ่ายจริง
